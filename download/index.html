Command-line tool

GeneFox analyses and the MCP server for AI assistants, from a terminal.

macOS and Linux

curl -fsSL https://genefox.app/cli/install.sh | bash

Windows (PowerShell)

irm https://genefox.app/cli/install.ps1 | iex

The installers check the release signature and each file's SHA-256 before installing anything.

Files

    Verify by hand

    Download SHA256SUMS and SHA256SUMS.minisig beside the file, then:

    minisign -Vm SHA256SUMS -P RWTc+F0bd3qlNlApONI2qRpbBAcrDfUhxdVUrsoaVYGdkaHjUWAB75BL && shasum -a 256 -c SHA256SUMS --ignore-missing
