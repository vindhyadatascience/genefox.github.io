# Tool catalogue

This table is generated from the server's tool registry by `genefox tools`, so it lists exactly the tools a build implements. To see the catalogue for the build you have installed, run `genefox tools`.

The **Access** column says when a client sees a tool:

- **free**: always listed.
- **Pro: \<capability\>**: listed only when that capability is granted. This build grants none.
- **legacy**: listed only with `--enable-legacy-tools`.

The **Deadline** column is the tool's own per-call deadline, which `--call-timeout` replaces. The **Summary** column is the first sentence of the description `tools/list` returns; `tools/list` also returns each tool's full description and input schema.
