# Survival

Compare TCGA overall survival between patients split at the median expression of one gene.

Cold-start time: `tcga_survival` 5–30 s; cached repeats are faster.

The examples use the session `s` from Getting started and need the GeneFox runtime.

```python
survival = api.tcga_survival(
    s,
    project="TCGA-BRCA",
    gene="ESR1",
    stratify="expression",
    width_in=6.5,
    height_in=4,
    dpi=300
)
```
