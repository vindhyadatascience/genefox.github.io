# Sample PCA

Project a cohort's samples onto principal components. PCA describes structure; it is not a test.

Cold-start time: `tcga_sample_pca` 30 s–5 min; cached repeats are faster.

The examples use the session `s` from Getting started and need the GeneFox runtime.

```python
pca = api.tcga_sample_pca(
    s,
    project="TCGA-BRCA",
    color_by="sample_type",
    width_in=6.5,
    height_in=4,
    dpi=300
)
```
