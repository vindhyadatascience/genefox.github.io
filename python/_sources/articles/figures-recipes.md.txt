# Figures and local expression

Figure tools take `format` (`png`, `svg` or `tiff`), `dpi`, and either a `size` preset or `width_in` with `height_in`. Tools that support it also return a recipe with `recipe = TRUE`.

Local expression data converts to and from GeneFox's import format without analysis.

```python
from pathlib import Path
import pandas as pd
import genefox
base = Path("path/to/local-expression")  # matrix.tsv, samples.tsv, experiment.json
matrix = pd.read_csv(base / "matrix.tsv", sep="\t", index_col=0)
samples = pd.read_csv(base / "samples.tsv", sep="\t", index_col=0)
x = genefox.ExpressionDataset.from_pandas(matrix, assay="logcounts", units="log2_cpm", sample_metadata=samples)
adata = x.to_anndata("logcounts")
manifest = x.write_import("new-import-directory", assay="logcounts", scale="log2")

```
