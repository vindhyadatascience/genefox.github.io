# Getting started

Install the GeneFox CLI 1.1.0 or later; it carries the GeneFox runtime, which is proprietary and not bundled with this package.

Then install the package:

```sh
pip install genefox
```

```python
import genefox
from genefox import api
s = genefox.Session(runtime="path/to/runtime", output="output")
status = api.account_status(s)
```

## Result contracts

- `account_status`: <https://genefox.app/schemas/v1/account-status-result-v1.schema.json>
